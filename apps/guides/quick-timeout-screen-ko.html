아이폰 화면을 일정 시간 켜 두는 방법

Quick Timeout에서 시간을 선택하고 세션을 시작한 뒤 작은 Picture in Picture 상태 창을 유지하세요. 레시피나 참고 자료를 보는 동안 선택한 시간이 끝날 때까지 화면 유지 세션이 동작합니다.

무료 · 광고 포함

화면 유지 시작하기

  1. 10분, 30분, 45분을 선택하거나 직접 시간을 설정합니다.
  2. 시작을 누르고 Picture in Picture 상태 창이 나타나는지 확인합니다.
  3. 레시피, 악보, 타이머 또는 참고 자료를 볼 앱으로 이동합니다.
  4. 끝내려면 Quick Timeout의 종료 버튼이나 PiP의 닫기 버튼을 사용합니다.

화면이 다시 꺼질 때

PiP 창 확인

Quick Timeout은 PiP 세션을 이용합니다. PiP를 닫으면 화면 유지 세션도 종료될 수 있습니다. 창이 방해되면 화면 가장자리로 밀어 작게 숨길 수 있습니다.

다른 미디어 재생

동영상이나 음악 앱이 PiP 또는 미디어 재생을 시작하면 iOS가 기존 PiP 세션을 중단할 수 있습니다. 다른 미디어를 멈춘 뒤 Quick Timeout에서 새 세션을 시작하세요.

수동 잠금

측면 버튼으로 기기를 직접 잠그는 동작은 세션과 별개입니다. 잠금 해제 후 앱 상태를 확인하세요.

시스템 자동 잠금과의 차이

Quick Timeout은 iOS 설정의 자동 잠금 값을 변경하지 않습니다. 선택한 시간 동안 보이는 PiP 상태와 함께 화면 유지 세션을 제공하며, iOS의 PiP와 미디어 동작에 영향을 받을 수 있습니다.
