Quick Timeout / iPhone and iPad guide

How to keep an iPhone screen awake for a set time

Choose a time in Quick Timeout, start the session, and keep the small Picture in Picture status visible. The screen-awake session runs until the selected time ends while you view a recipe or reference.

Download Quick Timeout on the App Store

Free with ads

Start a screen-awake session

  1. Choose 10, 30 or 45 minutes, or enter a custom time.
  2. Tap Start and confirm the Picture in Picture status appears.
  3. Move to your recipe, sheet music, timer or reference app.
  4. Use End in Quick Timeout or close the PiP window when you are finished.

If the screen starts locking again

Check the PiP window

Quick Timeout uses a PiP session. Closing PiP can end the screen-awake session. If the window is in the way, move it to the screen edge.

Other media playback

When another video or audio app starts PiP or media playback, iOS can interrupt the existing session. Stop the other media and start a new Quick Timeout session.

Manual locking

Pressing the side button locks the device independently of the session. After unlocking, return to the app and check the session state.

How this differs from Auto-Lock

Quick Timeout does not change the iOS Auto-Lock setting. It provides a timed screen-awake session with a visible PiP status and remains subject to iOS PiP and media behavior.
