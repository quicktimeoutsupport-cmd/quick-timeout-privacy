Link Now / Android troubleshooting

Bluetooth headphones not showing in Link Now

Link Now shows Bluetooth audio devices that are already paired in Android Settings. Pair a new device there first, then return to Link Now or use Refresh.

Get Link Now on Google Play

Free with ads

Add a new device

  1. Turn on your headphones, speaker or car audio and put it in pairing mode.
  2. Pair it from the Bluetooth page in Android Settings.
  3. Return to Link Now. The current version reloads the list after you return from Settings.
  4. If it is still missing, tap Refresh, choose the device and save it to a profile.

If it still does not appear

Nearby devices access

Check Link Now under Android app permissions. Without Nearby devices access, the app cannot read the paired-device list.

Power and active connections

Confirm the accessory is powered on and is not occupied by another phone. The number of simultaneous connections varies by device.

Restart Bluetooth

Turn Android Bluetooth off and on, then refresh again. If Link Now reports a list error, wait briefly and retry.

About the connection helper

Android does not expose a general public API that lets every app force all Bluetooth audio connections. Basic mode uses system Bluetooth settings. The optional helper requires separate setup, and connection behavior can vary by device.
