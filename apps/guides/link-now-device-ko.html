Link Now / Android 문제 해결

블루투스 이어폰이 목록에 안 보일 때

Link Now는 Android 설정에 이미 페어링된 블루투스 오디오 기기를 보여줍니다. 새 기기는 시스템 설정에서 먼저 페어링한 다음 앱으로 돌아오거나 새로고침을 눌러야 합니다.

Google Play에서 Link Now 설치

무료 · 광고 포함

새 기기를 등록하는 순서

  1. 이어폰·스피커·차량 오디오의 전원을 켜고 페어링 모드로 전환합니다.
  2. Android 설정의 블루투스 화면에서 기기를 페어링합니다.
  3. Link Now로 돌아갑니다. 최신 버전은 설정에서 돌아오면 목록을 다시 불러옵니다.
  4. 기기가 보이지 않으면 상단 새로고침 버튼을 누른 뒤 기기를 선택해 프로필에 저장합니다.

그래도 보이지 않을 때

근처 기기 권한

Android 설정에서 Link Now의 근처 기기 권한이 허용되어 있는지 확인하세요. 권한이 거부되면 앱이 페어링 목록을 읽을 수 없습니다.

전원과 연결 상태

기기 전원이 켜져 있고 다른 휴대전화에 연결되어 있지 않은지 확인하세요. 기기마다 동시에 유지할 수 있는 연결 수가 다릅니다.

Bluetooth 다시 켜기

Android 블루투스를 잠시 껐다 켠 뒤 Link Now에서 다시 새로고침해 보세요. 목록 조회 오류가 표시되면 잠시 후 재시도할 수 있습니다.

연결 도우미에 관하여

Android는 일반 앱이 모든 블루투스 오디오 연결을 강제로 바꾸는 공개 기능을 제공하지 않습니다. 기본 모드는 시스템 블루투스 설정을 이용하며, 선택형 연결 도우미는 별도 안내와 설정이 필요합니다. 기기별 연결 동작은 다를 수 있습니다.
